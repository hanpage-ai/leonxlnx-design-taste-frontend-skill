# leonxlnx-design-taste-frontend-skill

> 247개 어워드 사이트 연구에서 주제에 맞는 디자인 방향 1개를 골라주고, "AI가 자꾸 만드는 패턴"을 컴퓨터가 직접 확인해 걸러내는 스킬.

## 이 스킬의 역할

AI가 만든 화면이 "틀린 건 없는데 아무것도 결정된 게 없다"는 느낌이 들 때,
이 스킬은 **247개 사이트 연구**로 화면을 다시 만듭니다.

- 247개 어워드 사이트 연구를 참고해 "이 주제에 맞는" 디자인 방향 하나를 골라주고, 그 방향의 글씨·색·구성을 씀
- 화면의 아이디어를 그 회사만의 거리·이름·라벨 같은 단서로 엮어 냄
- "제목 3줄, 그라디언트, 어디에나 뿌려진 그림자" 같은 AI 패턴을 컴퓨터가 3개 화면 크기에서 직접 확인해 걸러냄

## 누가 쓰면 좋은지

- **랜딩페이지·마케팅 사이트를 만드는 개발자**: "AI가 만든 것 같은" 느낌에서 벗어나 주제 그 자체처럼 보이는 화면을 원할 때
- **포트폴리오를 만드는 사람**: 모두 같은 화면이 아니라 이 "주제"만의 화면을 원할 때
- **AI로 화면을 만드는 팀**: "247개 레퍼런스 + AI 패턴 실측"으로 품질 기준을 자동화하고 싶을 때
